# 🏅 קרב המדליה — גרסה 2

משחק מולטיפלייר בזמן אמת עם שלושה משחקים, לוח תוצאות משותף ושמירת התקדמות בדפדפן.

---
Two additional games were added, and the React template design was modified to replace the base version.

## הפעלה מהירה

צריך Node.js בגרסה 18 ומעלה.

```bash
# חלון טרמינל ראשון — השרת
cd server
npm install
npm start          # רץ על http://localhost:3000

# חלון טרמינל שני — הלקוח
cd client
npm install
npm run dev        # נפתח על http://localhost:5173
```

לפרסום בשרת אמיתי:

```bash
cd client && npm run build    # נוצרת תיקיית client/dist
cd ../server && npm start     # השרת מגיש את הבילד בעצמו
```

## איך עובד הניקוד

שלושת המשחקים משתמשים באותו מנוע (`shared/scoring.js`):

| רכיב | חישוב |
|---|---|
| ניקוד בסיס לשאלה | `שלב × 2` — שלב 1 = 2 נק', שלב 2 = 4, שלב 3 = 6… |
| בונוס מהירות | עד פי 2 מהבסיס, לפי כמה זמן נשאר |
| עליית שלב | כל 5 הצלחות |
| **דירוג סופי** | `נקודות + (נקודות לדקה × 5)` |

הדירוג הוא מה שקובע את סדר לוח התוצאות, ולכן מי שצברה 300 נקודות
בשלוש דקות תדורג מעל מי שצברה 300 נקודות בעשר דקות. זמן בהשהיה
ובמסך הכישלון לא נספר.

## רמות קושי

`levelConfig()` מגדיר את ההקשחה לכל המשחקים יחד:

- **צורות על המסך:** מתחיל ב-4 ועולה עד 12
- **זמן לשאלה:** 8 שניות בשלב 1, יורד ב-0.45 שניות לשלב, רצפה של 2.5 שניות
- **מהירות במשחקי התנועה:** עולה ב-18% לכל שלב
- **מכשולים / שודדים:** עד 12 במקביל

## שמירה בדפדפן

השמירה היא ב-`localStorage`, כלומר לפי דפדפן ולפי מחשב — בלי הרשמה.
לכל משחק יש מגירה נפרדת:

```
medal-battle:progress:shapes → { roomCode, name, points, level, activeMs }
medal-battle:progress:car    → { ... }
medal-battle:progress:dollar → { ... }
```

- חזרה **לאותו חדר באותו משחק** → ההתקדמות נטענת וממשיכים.
- מעבר **לחדר אחר באותו משחק** → נפתחת אזהרה שהנקודות יימחקו, ורק אישור מפורש ממשיך.
- מעבר **למשחק אחר** → הנקודות של המשחק הקודם נשארות במגירה שלהן ולא נוגעים בהן.
